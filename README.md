# SwipeFlow · 医学题库（MD3 手机版）

一个基于 **Material Design 3** 规范打造的离线医学题库 Web App（H5）。手机浏览器可直接打开，也可借助 HBuilderX 打包为 Android APK。

- 当前版本：**v4.2**
- 设计规范：`Android-MD3-Knowledge`（Material Design 3 官方规范知识库）
- 数据：内置 7 科约 **6202 道题**，完全离线，无账号、无网络请求

---

## 一、快速开始

### 方式 1：直接用浏览器打开
双击 `index.html` 即可在桌面浏览器查看；用手机浏览器打开时建议通过本地服务器或部署到静态站点，以获得完整体验。

### 方式 2：本地预览（推荐）
在本目录执行：

```bash
python3 -m http.server 8080
```

然后手机与电脑处于同一 Wi-Fi，访问 `http://<电脑IP>:8080/index.html`。

### 方式 3：打包成 Android APK
1. 用 **HBuilderX** 打开本目录（含 `manifest.json`）。
2. 右键 `manifest.json` → 确认 appid、应用名称、图标（默认 `images/icon.png`）。
3. 菜单「发行」→「原生 App 云打包」→ 选择 Android → 打包。
4. 生成的 APK 可直接安装到手机。

> `manifest.json` 已配置好基础信息；如需上架应用市场，请自行补充签名证书与隐私合规信息。

## 二、功能特性

- **7 科内置题库**：妇产科学、内科学、外科学、儿科学、口腔科学、眼科学、耳鼻咽喉头颈外科学（约 6202 题）
- **三级导航**：题库 → 科目 → 章节 → 题目，中央展开卡片式过渡动画
- **刷题模式**：顺序练习、随机练习、章节练习；支持单选题 / 多选题
- **收藏与错题本**：按学科分类的收藏夹，答错自动收录，可回看与改答案
- **学习统计**：累计刷题、正确率、各科完成进度，本地持久化
- **搜索与导入**：题库内搜索、按模板导入自有题库、JSON 备份导出
- **键盘 / 手势**：桌面端支持 `←` `→` 切题、`Esc` 返回

## 五、技术实现

- **配色**：基于 `@material/material-color-utilities` 的 HCT 色彩空间，从种子色派生 26+ 色彩角色；通过动态注入 `<style id="palette-vars">` 覆盖 `:root` / `[data-theme="dark"]` 实现切换。
- **动效**：MD3 Expressive 弹簧曲线（`cubic-bezier`）、state layer 涟漪、中央展开卡片转场。
- **进度条**：Flat 为 4dp 轨道 + primary 填充 + 4dp stop 圆点；Wavy 用 SVG mask 实现平滑正弦波并带流动动画。遵循 MD3 `progress-indicator` 规范。
- **存储**：全部状态存于 `localStorage`（主题、进度、收藏、错题、统计），无需后端。
- **无障碍**：图标按钮带 `aria-label`，进度条遵循减少动画偏好，控件支持键盘焦点。
